# poler-api — AI-шлюз к poler-engine (самодокументируемая поверхность)

Один бинарник чистого `std` (`rustc -O poler-api.rs -o poler-api`), который
делает возможности **установленного** `poler-engine` (>= 0.61.0) видимыми
любой LLM/агенту — без пересборки движка.

## Зачем

| Проблема | До | После |
|---|---|---|
| Дискаверабилити CLI | 250 флагов, 947 строк `--help` — модель тонет | `poler-api schema` — один JSON-манифест |
| Дискаверабилити MCP | doc обещал 8 инструментов, живой сервер отдаёт 32 (calc/quantum/**нейросеть**/fly/ssn скрыты) | MCP-прокси: 32 живых инструмента движка насквозь + 2 нативных |
| eigen при больших n | взрыв Уилкинсона на n>=28 (коэффициенты charpoly растут O(n!)) | `poler_matrix_eigen_sturm`: Штурм-бисекция, машинная точность при n=256+ |
| tridiag-билдер | n<=64 | n<=100000 (континуанта O(n)) |

## Поверхность

```
poler-api                          # человекочитаемая сводка
poler-api schema [--compact]       # ПОЛНЫЙ JSON-манифест (живые MCP-инструменты движка + нативные)
poler-api mcp                      # MCP-сервер stdio JSON-RPC 2.0 (прокси движка + нативное ядро)
poler-api calc '<expr>' [--json]   # Калькулятор Всего движка
poler-api solve 'x^2 - 4 = 0'      # уравнения
poler-api convert '5 km to mi'     # единицы
poler-api hw [--json]              # скрытые параметры ПК
poler-api matrix det|eigen|trace <источник>
       источники: tridiag:2,-1,256 | file:matrix.csv | inline:2,1;1,2
poler-api neural speak '<текст>' [--tokens N]      # живая нейросеть Триединства
poler-api quantum run|verify|teleport|bloch|list … # квантовый мост (MCP poler_quantum)
poler-api search <путь> '<запрос>'                 # топографический поиск
poler-api grep <путь> '<паттерн>' [--regex] [-i]   # точный grep
poler-api selftest                 # батарея честности: 15 проверок
```

## Числа (протокол 2026-10-01, selftest 15/15 PASS)

- `matrix eigen tridiag:2,-1,256` — 256 собственных значений,
  **max_err = 2.8e-14** против аналитики `2-2cos(kπ/257)`,
  `prod(λ) = 257.00000004 = det`, `Σλ = trace` до 1.1e-13, 57 мс.
- Для сравнения: встроенный `eigen` движка на n=28 даёт погрешность 1.9e+06
  и мнимые части 6.4e+05 на чисто вещественной симметричной матрице —
  это не баг, это феномен Уилкинсона; лечится сменой алгоритма (Штурм),
  а не точности.
- MCP-прокси: initialize → tools/list → **34 инструмента** (32 движка + 2
  нативных), нативный `poler_matrix_eigen_sturm` через прокси —
  `prod_lambda = 65.0000` на tridiag(2,-1,64).
- Квантовый мост: `quantum run qft --n 8` — полное распределение Борна,
  энтропия 8.000000000000002 бит, норма 1.0.

## Архитектура

```
агент/LLM ── подкоманды/MCP ──> poler-api ──делегаты──> poler-engine (CLI/MCP)
                                   │
                                   └── нативное Штурм-ядро (LU, континуанта,
                                       Хаусхолдер, Штурм-бисекция) — то, чего
                                       в движке нет до v0.62
```

Шлюз **не дублирует** логику движка: поиск/квант/нейросеть/калькулятор
делегируются родному бинарнику (`--exec … --json`, `--mcp`, `--triune-speak`);
нативным остаётся только матричное ядро, снятое с повестки Уилкинсона.
В v0.62 движка `eigen_sturm` вшит в калькулятор — шлюз остаётся фасадом
для бинарников 0.61.x и MCP-прокси с расширенным списком инструментов.

## Установка

```bash
rustc -O tools/ai-gateway/poler-api.rs -o ~/.local/bin/poler-api
poler-api selftest   # 15/15 PASS = готово
```

Требования: `poler-engine` в PATH (>= 0.61.0). Для MCP-клиентов
(Claude Desktop, Cursor, …): `command: poler-api`, `args: ["mcp"]`.
