# POLER Reader — приложение живого голоса для книг

> Директива владельца (после цикла K): «до рынка читалок нужно вначале
> приложение». Это оно: движок + формат + CLI + команда шелла.

## Что это

Книга превращается в звук **роторным резонатором живого голоса** (цикл K,
`scripts/shannon_bypass/living_voice/`) — но теперь с **коартикуляцией**:
один резонатор ведёт состояние ψ непрерывно через всю книгу, а формантные
цели F1/F2/F3 плывут от звука к звуку (τ ≈ 40 мс), как настоящий речевой
тракт. Звук не «переключается» между фонемами — он **перетекает**.

Каноническое уравнение `ṗ = −η·Π_Λ[D·p + γ·J·p + ∇F]`:

| Компонент | Воплощение |
|---|---|
| `J = A − Aᵀ` | ротор: фазы формант + вихревые перекачки (личность из семени) |
| `D` | дисипация (смуги BW): энергия между импульсами монотонно падает |
| `∇F` / вход | тритная щель `{−1,0,+1}` (No-Mul слой) + импульс Розенберга |
| `Π_Λ` | Мак-Віні 3P²−2P³ на когерентности состояния |

## Формат .poler-book

Одна книга = один файл: **текст + паспорт интонаций** (по записи на фразу:
64-битный сид + архетип + пауза). Волна — чистая функция `(текст, сид,
личность)`, поэтому:

- аудиокнига на 10 часов **< 1 МБ** (сжатие ×1500 и больше против PCM);
- один `seed` = один голос навсегда (та же личность в любой книге);
- хватило бы даже <0.5 кбит/с на потоковом канале.

## CLI

```text
poler-reader voices                                # 4 диктора (архетипы)
poler-reader pack книга.txt -o книга.poler-book --voice a_calm --seed 4242
poler-reader render книга.poler-book -o демо.wav --seed 4242
poler-reader info книга.poler-book
poler-reader verify --seed 4242                    # V1–V8, 10 аксиом
```

Форматы входа: `.txt` / `.md` / `.fb2` / `.poler-book`.

## Внутри poler-shell (v0.47.0)

```text
poler> read книга.txt --out демо.wav --voice a_calm --seed 4242
✓ демо.wav — 20.3 с звука, 7 фраз, 2529 периодов щели, jitter 0.49%
книга: 499 Б; WAV: 896038 Б (сжатие ×1796)

poler> read --info книга.poler-book
poler> poler-engine --exec 'read книга.txt' --json     # агентный конверт
```

## Архитектура (ноль внешних зависимостей)

| Модуль | Ответственность |
|---|---|
| `rng` | xorshift64 — бит-в-бит как в эталоне цикла K |
| `trit` | щель {−1,0,+1}: сдвиг+инверсия+своп, число нулей — инвариант |
| `linalg` | expm 6×6 (скейлинг-квадрат+Тейлор), гаусс, Якоби-собственные |
| `resonator` | ZOH-дискретизация `(J−D)` блоками по 32 сэмпла |
| `voice` | LivingVoice: калибровка усиления, микротремор, вибрато |
| `phonemes` | текст ru/uk → сегменты (архетипы, контур F0 по Tune) |
| `book` | парсер txt/md/fb2 → фразы |
| `polerbook` | бинарный формат .poler-book (pack/unpack) |
| `stream` | потоковый рендер книги: коартикуляция, паузы, нормировка |
| `fft` | radix-2 FFT + кепстр (верификация) |
| `verify` | suite V1–V8 |

## Честные ограничения v1

- Фонетика ru/uk — упрощённые правила (гласные→архетипы, согласные —
  звонкие/глухие/удлинители); ударение не моделируется.
- F3 слабо выражен в топ-пиках спектра (гармоники F0 доминируют);
  LPC-огибающая его видит.
- Никакого сравнения с нейро-TTS по разборчивости — это роторный
  синтез с другим назначением: идентичность + сжатие + живость.
