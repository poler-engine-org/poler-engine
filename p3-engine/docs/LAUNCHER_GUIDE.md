# Лаунчер P3 Engine

Лаунчер P3 Engine — полностью новый графический интерфейс на **Zig + raylib**, написанный с нуля для замены O3DE лаунчера.

## Запуск

```bash
zig build run-launcher
```

Или через скрипт:
```bash
./tools/launch_p3.sh
```

## Возможности

- Главное меню с анимированным проективным фоном (сетка S3)
- Браузер проектов (создание, открытие, управление)
- Настройки движка (видео, физика, проективная геометрия, управление)
- Браузер ассетов (сцены, модели, текстуры, шейдеры)
- Экран загрузки со сприн-анимацией (по паттерну UE SpringMath)
- Обзор модулей движка

## Технологии

- **Язык**: Zig 0.14.0
- **Рендеринг GUI**: raylib (C99)
- **Анимация UI**: Сприн-система по паттерну UE SpringMath, переписанная на Zig
- **Интеграция**: Полная связь с модулями P3 Engine (p3_math, p3_kernel, и т.д.)
- **Язык интерфейса**: Русский

## Сборка

```bash
zig build launcher        # Только собрать
zig build run-launcher   # Собрать и запустить
```

## Архитектура

- `examples/p3_launcher.zig` — исходный код лаунчера
- `tools/launch_p3.sh` — скрипт запуска
- Цель `launcher` в `build.zig` — сборка через zig build
