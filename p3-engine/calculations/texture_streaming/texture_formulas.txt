P3 ENGINE — TEXTURE STREAMING DERIVATIONS
============================================================

1. MIPMAP LEVEL DERIVATION
----------------------------------------
Given pixel (x, y) with texture coords (u, v):
  ∂u/∂x, ∂v/∂x = partial derivatives of u,v wrt pixel x
  ∂u/∂y, ∂v/∂y = partial derivatives of u,v wrt pixel y
  W_tex = texture width in texels

  λ = log2(max(|∂u/∂x|, |∂v/∂x|, |∂u/∂y|, |∂v/∂y|) × W_tex)

  λ = 0: 1:1 texel/pixel ratio (no minification)
  λ = 1: 2:1 ratio (use 1/2 mip)
  λ = 2: 4:1 ratio (use 1/4 mip)
  λ < 0: magnification (need bilinear from level 0)

2. TOTAL MIPMAP MEMORY
----------------------------------------
Total = W × H × (1 + 1/4 + 1/16 + 1/64 + ...) = (4/3) × W × H
  Overhead: +33% vs single-level texture
  For 1024×1024 RGBA8: 5.33 MB → 7.11 MB (with mip chain)

3. ANISOTROPIC FILTERING
----------------------------------------
At grazing angles, pixel footprint becomes ellipse (length/width = aniso)
Standard: sample N lines along long axis (N = aniso level: 2, 4, 8, 16)
Each sample at: min(λ_long_axis, λ_short_axis + log2(aniso))
Result: sharp textures at grazing angles (no blur)

4. TEXTURE COMPRESSION FORMATS
----------------------------------------
BC7 (8 bytes per 4×4 block = 0.5 byte/texel):
  Best quality, RGBA, used for color/albedo/normal maps
BC1 (8 bytes per 4×4 block = 0.5 byte/texel):
  RGB only (no alpha), 5:6:5 color, used for diffuse textures
ASTC 4×4 (16 bytes per 4×4 = 1.0 byte/texel):
  Better than BC7, configurable block size, mobile-friendly
