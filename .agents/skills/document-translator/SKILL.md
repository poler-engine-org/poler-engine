# 🌐 Document Translator — Professional Technical Translation Skill

Навык **document-translator** предоставляет полный инструментарий и правила для высокоточного перевода технической документации, математических трактатов, API-спецификаций и архитектурных документов.

---

## 🎯 Ключевые принципы и инварианты перевода

1. **Сохранение математики и формул (LaTeX Invariant):**
   - Все инлайн-формулы `$ ... $` и блочные формулы `$$ ... $$` остаются **нетронутыми**.
   - Обозначения переменных ($x$, $\psi$, $J$, $\Phi$, $\oplus$, $\otimes$) не переводятся.
   - Математические операторы и индексы сохраняются в исходном виде.

2. **Сохранение кода и диаграмм:**
   - Все блоки кода ```` ```lang ... ``` ````, имена функций, типов, файлов и путей остаются без изменений.
   - Диаграммы Mermaid (`flowchart`, `sequenceDiagram`, `classDiagram`) переводятся только в текстовых метках внутри узлов (`["Метка"]`), синтаксис графа не меняется.

3. **Сохранение ссылок и якорей:**
   - Структура ссылок `[Текст](file:///path#anchor)` сохраняется: переводится только видимый текст ссылки, URL/путь остаётся неизменным.

4. **Терминологический словарь (Glossary Preservation):**
   - Специальные термины POLER/системной разработки переводятся согласованно:
     - *Statevector* $\rightarrow$ Вектор состояния / Стейтвектор
     - *Skew-symmetric rotor* $\rightarrow$ Кососимметричный ротор
     - *Strict Avalanche Criterion (SAC)* $\rightarrow$ Строгий лавинный критерий
     - *Zero-Storage Streaming* $\rightarrow$ Потоковая обработка с нулевым хранением
     - *Branchless SIMD* $\rightarrow$ Безветвевой SIMD

## 🛠️ Встроенные скрипты

### 1. Парсер и транслятор Markdown (`scripts/translate_markdown.py`)
Разбивает документ на блоки (заголовки, параграфы, формулы, код), изолирует непереводимые фрагменты (защитные плейсхолдеры `__CODE_BLOCK_N__`, `__MATH_BLOCK_N__`) и собирает обратно после перевода:

```bash
python3 .agents/skills/document-translator/scripts/translate_markdown.py --input docs/THEORY.md --target-lang uk --output docs/THEORY_UK.md
```

### 2. Пакетная валидация структуры после перевода:
Скрипт сверяет количество формул, ссылок и кодовых блоков в оригинале и переводе:
```bash
python3 .agents/skills/document-translator/scripts/verify_translation_parity.py --orig docs/THEORY.md --trans docs/THEORY_UK.md
```
