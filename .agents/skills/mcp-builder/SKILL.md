# 🔌 MCP Builder — Model Context Protocol Generator

Навык **mcp-builder** обучает агента создавать и конфигурировать серверы Model Context Protocol (MCP) для прямого взаимодействия с низкоуровневыми утилитами, аппаратными стендами и сервисами.

---

## 🚀 Сценарии использования
1. **Мост с QEMU Monitor / GDB:** создание локального MCP-сервера для прямого считывания дампов регистров CPU, фреймбуфера и страниц памяти.
2. **Интеграция сторонних систем:** подключение кастомных протоколов обмена данными с ядром POLER-OS.
