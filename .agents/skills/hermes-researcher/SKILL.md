# 🛰️ Hermes Researcher — Deep Technical Scraping & OSINT

Навык **hermes-researcher** обучает агента автономно находить, фильтровать и структурировать глубокую техническую документацию из открытых источников.

---

## 🔍 Сценарии использования
1. **Парсинг спецификаций UAPI / POSIX / Win32:**
   - Быстрый сбор структур данных (`ioctl`, заголовки C-библиотек, форматы пакетов).
2. **Сбор датасетов для дообучения локальных моделей:**
   - Фильтрация шума и рекламы, сохранение чистого структурированного Markdown для RAG-индексации в `poler-engine`.
