# 🧠 OpenClaw Memory Kit — Context & Knowledge Retention

Навык **openclaw-memory** предназначен для структурированного сохранения долговременной памяти и передачи критических архитектурных инвариантов между сессиями агентов.

---

## 🛠️ Возможности
1. **Fact & Decision Logging:**
   - Автоматическая фиксация закрытых багов (как clobber R10, 0xAAAA-утечка, demand-zero) в единый репозиторий знаний.
2. **Context Compression:**
   - Сжатие многотысячных логов сборки и дампов в компактные структурные выжимки (Summary Matrix) без потери ключевых адресов памяти.
