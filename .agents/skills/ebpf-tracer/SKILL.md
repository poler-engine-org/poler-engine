# ⚡ eBPF & Dynamic Kernel Tracer

Навык **ebpf-tracer** специализируется на непрерывной трассировке событий ядра и пользовательского пространства с минимальным оверхедом.

---

## 🛠️ Возможности
1. **Syscall Latency Tracking:**
   - Замер точного времени нахождения в Ring 0 для каждого системного вызова.
2. **Kprobe/Uprobe Hooking:**
   - Перехват входов и выходов функций без изменения исходного бинарного кода.
3. **Lock Contention & Deadlock Detection:**
   - Анализ времени удержания спинлоков и мьютексов в многопоточном окружении (SMP).
