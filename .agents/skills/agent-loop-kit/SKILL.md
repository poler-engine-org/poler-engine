# 🔄 Agent Loop Engineering Kit — Self-Healing & Execution Guard

Навык **agent-loop-kit** (методология AI-Операционки / OpenClaw) обучает агента безопасным паттернам исполнения, выходу из бесконечных циклов и самолечению при ошибках.

---

## 🎯 Ключевые паттерны
1. **Dry-Run & Human-in-the-Loop Guards:**
   - Предотвращение деструктивных действий (удаление критических файлов, форматирование) без предварительной валидации.
2. **Anti-Stall & Loop Detection:**
   - Детект повторяющихся однотипных ошибок в логах ядра / QEMU и мгновенная смена стратегии вместо слепых повторов.
3. **Crash Recovery Protocol:**
   - Сохранение контрольных точек состояния (checkpoints), мгновенный откат при OOM или сбоях FUSE.
