# Отчёт POLER Engine: Аудит, диагностика и устранение проблем в Linux (CachyOS x86_64)

**Дата:** 2026-09-17  
**Версия движка:** `poler-engine v0.30.0` (`pnd-ffi`, release)  
**Объект аудита:** Локальная рабочая станция Linux (CachyOS, Intel Core i7 Ivy Bridge, NVIDIA GPU, KWin Wayland).

---

## 1. Методология и цели проверки
Цель тестирования — проверка возможностей поисково-аналитического движка **POLER Engine** на реальной («грязной») операционной системе:
1. Гарантированный поиск ошибок, варнингов и аномалий в ротируемых и сжатых логах (`/var/log`, `.log.gz`, `journal`).
2. Диагностика графического стека (Wayland, DRM, NVIDIA NVRM).
3. Анализ сборки модулей ядра (DKMS, mkinitcpio, Limine).
4. Проверка состояния подсистем хранения (SATA, Btrfs/EXT4, systemd-journald).

---

## 2. Результаты аудита и статус устранения

### 2.1. 🔴 DKMS и несовпадение заголовков ядра (Nvidia & VirtualBox) — [ИСПРАВЛЕНО ✅]
* **Исходная ошибка:** В `/var/log/pacman.log` хуки DKMS падали с ошибкой `Missing 7.2.4-arch1-2 kernel modules tree` из-за установленного пакета `linux-headers` (от стандартного ядра Arch), в то время как в системе используются ядра CachyOS (`linux-cachyos` и `linux-cachyos-lts`).
* **Действие:** Удалён сиротский пакет `linux-headers`.
* **Результат:** `dkms status` чистый — модули `nvidia 550.163.01` и `vboxhost 7.2.16` успешно и без ошибок привязаны к обоим активным ядрам CachyOS.

---

### 2.2. 🟠 Графический стек KWin Wayland (DRM & Atomic Modeset) — [ИСПРАВЛЕНО ✅]
* **Исходная ошибка:** KWin Wayland падал с ошибкой `Atomic modeset commit failed! Некоректний аргумент` при переключении видеорежима на драйвере Nvidia.
* **Действие:** Создан конфигурационный файл `/etc/modprobe.d/nvidia.conf`:
  ```ini
  options nvidia-drm modeset=1 fbdev=1
  options nvidia NVreg_PreserveVideoMemoryAllocations=1
  ```
  Включены системные службы `nvidia-suspend`, `nvidia-hibernate`, `nvidia-resume` для сохранения видеопамяти при выходе из сна.
* **Результат:** Драйвер DRM корректно инициализирует кадровый буфер `fbdev=1`, предотвращая рассинхронизацию атомарных коммитов в KWin Wayland.

---

### 2.3. 🟡 Дисковая подсистема и безопасность `/boot` — [ИСПРАВЛЕНО ✅]
* **Исходная ошибка:** `bootctl` выдавал предупреждение безопасности о незащищённых правах случайного сида в `/boot`.
* **Действие:** В `/etc/fstab` добавлены строгие маски доступа для раздела EFI: `fmask=0177,dmask=0077`.
* **Результат:** Файлы ядра, конфигурации и random-seed защищены от несанкционированного чтения обычными пользователями (`0600`/`0700`). Целостность системных журналов подтверждена (`journalctl --verify` — PASS).

---

### 2.4. 🔵 Ошибка KVM модуля на процессоре Intel — [ИСПРАВЛЕНО ✅]
* **Исходная ошибка:** Ядро регистрировало ошибку при загрузке: `kvm_amd: CPU 1 isn't AMD or Hygon`.
* **Действие:** Создан файл `/etc/modprobe.d/kvm-intel.conf` с директивой `blacklist kvm_amd`.
* **Результат:** Исключены ложные попытки загрузки модуля AMD KVM на платформе Intel Core i7.
