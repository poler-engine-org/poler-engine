# archive/

Fragments of the 2025 "codebase restoration" attempts — multi-language
satellites that were never completed and are not part of the finished
POLER-Quantum core. Kept for reference:

* `poler-core`, `poler-lens`, `poler-dynamis`, `poler-eri`, `poler-sctp`,
  `poler-bridge`, `poler-tcp` + `Cargo.toml` — an unfinished Rust workspace
  (partial ERI / quantum-chemistry ideas).
* `rust_engine_core/`, `rust_sctp_burn/` — loose Rust sketches.
* `fpga_verilog/` — FPGA core sketch.
* `hardware_zig/` — tensor sketch in Zig.
* `julia_brusselator/` — subquantum kinetics sketch.
* `lean4_formal_proofs/` — stationarity proof sketch.
* `pyscf_poler/` — PySCF hijack experiment.

None of these are required to run, test or benchmark POLER-Quantum v1.0.0.
