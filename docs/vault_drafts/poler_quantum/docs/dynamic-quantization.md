# Dynamic Continuous Quantization — POLER-Quantum как универсальный топологический компрессор

> **Статус:** вижен, зафиксирован дословно из сессии владельца 2026-08-27, с последующей доработкой под существующую реализацию `poler_quantum/`. Позиционируется **перед классическими методами квантования** (AWQ, GPTQ, SmoothQuant). Реализация — milestone RQ1–RQ6 (см. `rust-core-roadmap.md`).

## 1. Почему классическое квантование ломается на нестандартных архитектурах

Обычное квантование (INT4/INT8/FP4) — **статическое**:

1. Оно «режет» веса и активации матрицы на фиксированные сетки по жёстким диапазонам min/max или шкалам MSE.
2. Когда в архитектуре нет стандартных слоёв Attention `QKᵀ/√d` (например, в RWKV, Mamba, Spiking NN, Ternary BitNet, оптических или аналоговых процессорах), статическое квантование разрушает тонкие **фазовые и резонансные связи** («выбросы» / outliers).

AWQ, GPTQ и SmoothQuant умеют защищать outliers только там, где есть статистика активаций по знакомым слоям (Linear, Attention-проекции). Для не-трансформерных и гибридных систем такой статистики нет — и сжатие выжигает именно ту динамику, которая несёт смысл: медленные резонансы `R[n]`, антисимметричные повороты `J`, диссипативную стабилизацию `D`.

## 2. Квантование через фазовое кодирование

Вместо округления непрерывного числа `p ∈ [-1,1]` в дискретные биты (0..15 для 4 бит) вектор латентного состояния проецируется на угол поворота кубита:

```
θ_i = arccos(p_i),   |ψ_i⟩ = cos(θ_i/2)·|0⟩ + sin(θ_i/2)·|1⟩
```

При измерении (Born Sampling) вероятности

```
P(|0⟩) = (1 + p_i) / 2
```

**точно** передают вес — без квантового шума округления.

Для неизвестных архитектур это означает **адаптивное непрерывное представление вместо потери точности**: сетка квантования не выбирается заранее, она порождается самим состоянием. Именно эта кодировка уже реализована в `poler_quantum/quantum/ansatz.py` (`Ry(arccos p_i)` + entanglement-цепь) — вижен не отменяет её, а поднимает до роли основного механизма сжатия.

## 3. Динамическое сжатие по ε-значимости (Adaptive Bit-Depth)

В POLER квантование управляется энергией значимости `ε(W_t)`:

* **Низкая значимость** (`ε → 0`, фоновые/бытовые токены): фазовый анзатц сжимает состояние до 1–2 кубитов (или 1 бита / тритов `{−1, 0, +1}`), переводя систему в режим минимальной диссипации энергии.
* **Высокая значимость** (`ε ≫ 0`, ключевые концепты/кульминации): резонансный слой `J = A − Aᵀ` мгновенно разворачивает полное фазовое пространство высокой точности.

Квантование становится **динамическим во времени (`t`) и по топологии (`Σ`)**, а не статическим по всей сетке весов. Это прямое продолжение уже работающего механизма `η_eff = η·exp(β·tanh(ε̂))`: та же ε-модуляция, что управляет обучением, управляет и глубиной представления.

## 4. McWeeny Purification — чистильщик ошибок квантования

Главная беда агрессивного квантования (1–2 бита) — накопление систематической ошибки. В POLER заложена формула очистки матрицы плотности:

```
P_new = 3P² − 2P³
```

Если из-за квантования матрица проектора потеряла свойство идемпотентности (`P² ≠ P`), итерация МакВини возвращает квантованную матрицу **точно на многообразие Грассмана за 1–2 такта без переобучения всей модели** (для сеток ≥ 6 бит; грубые сетки требуют 3–5 тактов).

Свойства (проверяемые тестами):

* `P` близко к проектору → ошибка сжимается **квадратично** (полином кубический, порядок сходимости 2): измерено 8-битная сетка `6.3e-3 → 9.4e-9` за две итерации; `Tr(P)` сохраняется с точностью до целого — ранг не меняется; собственные значения стягиваются к `{0, 1}`;
* инвариант восстанавливается **точно** при любой коррупции, не пересекающей спектральную щель; подсистемное пространство дрейфует на величину ~коррупции — «ремонт, а не тождественное преобразование» (честно зафиксировано в тестах);

В гибридной петле это даёт цикл: `сжатие → деградация проектора → purification → восстановление инварианта Π_Λ² = Π_Λ` — сжатие становится **обратимым**, чего нет ни у одного классического метода.

**Реализовано в v1.1.0**: `poler_quantum/core/purification.py` (`mcweeny_purify`, `quantize_entries`, `idempotency_error`, `subspace_error`) + 26 тестов, включая честные ограничения (грубая сетка вращает подпространство).

## 5. Независимость от аппаратной платформы (неизвестные архитектуры)

Благодаря тому, что POLER оперирует инвариантами `HΨ = 0` и операторами `(D, J, Π_Λ)`:

* **Фотонные / оптические чипы:** фаза `θ` отображается на сдвиг фазы интерферометра Маха-Цендера — то же самое `Ry(θ)`, что в анзацe, только в опике, а не в схеме.
* **Мемристорные кроссбары (Neuromorphic):** оператор `D = LLᵀ` реализуется через проводимость синаптической проводимости.
* **FPGA / Multiplier-less:** оператор `R_t = ε_t + ρR_{t−1}` вычисляется сдвигами shift-and-add **без единого аппаратного умножителя DSP**.

Инвариант `HΨ = 0` (стационарность гамильтониана на многообразии состояний) не зависит от substrate — поэтому один и тот же сжатый формат исполняется на кремнии, оптике или мемристорах без переквантования.

## 6. Итог

POLER-Quantum — это не просто симулятор, а **универсальный топологический компрессор**. Он позволяет динамически квантовать состояние любых нейросетевых архитектур (включая не-трансформерные и гибридные квантово-классические системы) прямо во время инференса **без потери смысла**.
