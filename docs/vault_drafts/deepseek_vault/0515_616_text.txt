# Задание: создать ТЗ для реализации poler_core.rs

У тебя загружены документы проекта POLER (физика смысла, архитектура SCTP, цикл ℘→O→L→ε→R[n]). На основе кода-эталона (см. ниже) сгенерируй подробное ТЗ для другого ИИ (например, Z.ai). У того ИИ нет доступа к исходным документам, поэтому в ТЗ нужно раскрыть все скрытые смыслы (ссылки [n] соответствуют аксиомам из документов) и дать чёткие инструкции по реализации на Rust.
