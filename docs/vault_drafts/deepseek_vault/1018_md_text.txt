℘ → O → L → ε → R[n] → ℘′ → ...

Физическая интерпретация:

℘ (Перцепция) = измерение квантового состояния
O (Образ) = волновая функция после измерения
L (Логика) = операторы эволюции
ε (Энергия) = ожидаемое значение гамильтониана
R[n] (Резонанс) = рекуррентные квантовые корреляции
℘′ (Новое восприятие) = коллапс обновленной волновой функции
