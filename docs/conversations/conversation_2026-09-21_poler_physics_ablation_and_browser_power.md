## 🤖 Antigravity / POLER Agent

**Он делает реальные математические и физические расчёты в реальном времени (на лету).** Это не захардкоженные скрипты и не готовые ответы.

---

### Как это устроено внутри:

1. **Парсер выражений (AST):** Движок разбирает строку на синтаксическое дерево (числа, операторы, скобки, константы).
2. **База фундаментальных констант:** В память зашиты точные значения CODATA / СИ:
   * $c = 299\,792\,458 \text{ м/с}$
   * $G = 6.67430 \times 10^{-11} \text{ м}^3 / (\text{кг} \cdot \text{с}^2)$
   * $\hbar, k_B, e$ и др.
3. **Размерный анализ (Dimensional Algebra):** Каждая величина хранится как пара: `(число, вектор_размерностей)`. Движок по законам физики перемножает и делит размерности:
   $$\frac{\text{m}^3}{\text{kg} \cdot \text{s}^2} \times \text{kg} \div \frac{\text{m}^2}{\text{s}^2} = \text{m}$$
4. **Арифметика:** Производится честный расчёт на CPU с плавающей точкой.

---

### Как легко проверить лично:

Введите в `poler>` совершенно **любые нестандартные/случайные числа**, которых нет ни в каких базах или статьях:

1. **Радиус Шварцшильда для массы 75 кг (человек):**
   ```bash

   ```
   *(выдаст честный расчет порядка $1.11 \times 10^{-25} \text{ m}$ — размер меньше протона)*

2. **Радиус Шварцшильда для Юпитера ($1.898 \times 10^{27} \text{ kg}$):**
   ```bash
   poler> calc 2 * G * (1.898e27 kg) / c^2
   ```
   *(выдаст $\approx 2.818 \text{ m}$)*

3. **Случайная масса (например, 123456789.123 kg):**

Движок рассчитает любой физический закон и произвольное выражение со строгим контролем физических единиц.

Чтобы вводить команды «пачкой» (стопкой), есть 3 удобных способа:

---

### Вариант 1. Вставить пачкой прямо в `poler>` (без знака `#`)
Терминал выполнит каждую строку по очереди при вставке, главное — **убрать комментарии `#`**:

```text

```
*(Скопируйте весь блок целиком и нажмите `Ctrl+Shift+V` или `Shift+Insert` в шелле `poler>`)*.

---

### Вариант 2. Через файл скрипта `.poler`
Создайте файл (например, `physics.poler`):
```toml
[[calc]]
expr = "2 * G * (1.989e30 kg) / c^2"

[[calc]]
expr = "2 * G * (5.972e24 kg) / c^2"

[[calc]]
expr = "G * (5.972e24 kg) / (6371 km)^2"

[[calc]]
expr = "1 / sqrt(1 - 0.9^2)"

[[calc]]
expr = "(1 kg) * c^2"

[[calc]]
expr = "1 au / c"
```
И загрузите его командой:
```bash
poler> calc script physics.poler
```

---

### Вариант 3. Через терминал Linux (через перенаправление ввода / pipe)

```bash

```
Или в одну строку:

### 1. Дифференциал вычислительного потока (Скорость $dI/dt$)

Полная вычислительная производительность — это дифференциал переработанной информации $dI$ во времени:

$$dI = W \cdot \rho_{\text{bit}} \cdot (1 - \mu_{\text{stall}}) \cdot f \cdot dt$$

Где переменные состояния:
* $W$ — ширина шины/вектора (бит за операцию, например $W = 512\text{ бит}$ в SIMD или $W = 5\text{ трит/байт}$ в Trit5).
* $\rho_{\text{bit}} = -\sum p_i \log_2 p_i$ — информационная плотность (эффективность упаковки смысла в бит/трит).
* $\mu_{\text{stall}} \in [0, 1)$ — коэффициент задержки конвейера (промахи кэша, ожидание памяти DRAM).
* $f = \frac{1}{\tau}$ — частота тактового генератора.

**Вывод дифференциала:**
$$\frac{\partial I}{\partial W} = \rho_{\text{bit}} (1 - \mu_{\text{stall}}) f$$
$$\frac{\partial I}{\partial f} = W \rho_{\text{bit}} (1 - \mu_{\text{stall}})$$

Если конвейер ждёт память ($\mu_{\text{stall}} \to 1$), то:
$$\lim_{\mu_{\text{stall}} \to 1} \frac{\partial I}{\partial f} = 0$$
> **Физический смысл:** Повышение частоты $df > 0$ при простаивающем конвейере даёт **ноль прироста скорости** ($dI \to 0$). Решает только ширина $W$ и отсутствие простоя $\mu_{\text{stall}} \to 0$.

### 4. Дифференциал декогеренции (Классический кремний vs Кванты)

Эволюция классического битового состояния детерминирована:

```rust
    fn build_jacobian(&self, p: &[f64]) -> DMatrix<f64> {
        let nc = self.constraints.len();
        let nv = self.total_vars;
        let mut jc = DMatrix::zeros(nc, nv);
        for (i, c) in self.constraints.iter().enumerate() {
            let v: Vec<f64> = c.var_indices.iter().map(|&idx| p[idx]).collect();
            let mut lg = vec![0.0; c.var_indices.len()];
            (c.jacobian)(&v, &mut lg);

                jc[(i, idx)] = lg[k];
            }
        }
        jc
    }
```
