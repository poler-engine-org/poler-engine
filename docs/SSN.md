### 2.1 Реестр находок верификации (F1–F13)

Доказательство — это не формальность: сьют нашёл и заставил исправить
**13 реальных дефектов теории**, большинство из которых задокументировано
как режимы отказа в самих исходных диалогах:

| # | Находка | Исправление |
|---|---|---|
| **F1** | Стек без гомеостаза насыщается до 100% — «цифровая эпилепсия» (совпадает с историей v1.0: 1M/1M нейронов, avg_activation 0.985) | гомеостаз обязателен |
| **F2** | EQ-A22 (транскрипция из диалога 012) содержит **ошибку знака** в ветви гипоактивности: возбуждение сжимается, когда сеть недоактивна → смерть | corr = err·k; w>0 ×(1−corr); w<0 ×(1+corr) |
| **F3** | Золотой режим не всюду устойчив: при homeo=0.01 seed=42 умирает (гистерезис GABA→0.9) | homeo=0.02, запас прочности |
| **F4** | Эйлер на J дрейфует по норме (×4564 при h=0.01) | транспорт только Кэли: (I+hJ/2)(I−hJ/2)⁻¹ |
| **F5** | Критичность C=1/(1+\|CV−1\|) работает только на ограниченных величинах | считать по числу активных нейронов |
| **F6** | CSE без посимвольной фазы: все тексты коррелируют на cos≈0.92+ | фаза = код·φ (золотое сечение) mod 2π |
| **F7** | NMDA-гейт tanh(⟨state,ctx⟩) требует накопленного состояния | инициализация через Transmit-предысторию |
| **F8** | Гомеостаз по мгновенной активности → bang-bang 0%↔100% | медленный след f_sys (интегральный контроллер) |
| **F9** | polyfit на нулевой активности возвращает положительный шум → DA растёт во время смерти | тренд по спайковой метрике |
| **F10** | σ_a→0 во время смерти → 5HT→0.9 → gain падает → спираль смерти | согласование метрик |
| **F11** | CV=0/0=0 на мёртвой сети → NE падает вместо роста | защита деления |
| **F12** | **Несовпадение порогов**: метрика активности по порогу 0.01 принимала здоровый субпороговый фон (a≈0.065) за «98% активность» | ЕДИНОЕ определение: порог спайка a > 0.1 (EQ-A23) |
| **F13** | **Windup гомеостаза** (найден Rust-портом, seed=20260918): 80% весов у клипа 1.0, тормозные стёрты, активность 0.5% — интегральному контроллеру некуда расти | ретикулярный тон: b ← clip(b + k_b·(target − f_sys), 0, b_max) — второй интегральный канал, не насыщается |

F13 — показательный случай: **Rust-порт с более широким покрытием seed
вскрыл дефект, который Python-доказательство на своих траекториях не
поймал** (там те же seed'ы давали 1.6% — формально выше пола 1%, но с
тем же паттерном 80% весов на клипе). Диагноз → пруф
([`proofs/ssn_f13_proof.py`](../proofs/ssn_f13_proof.py): 10/10 seed × 10k
шагов здоровы, w@клип ≤ 1.9%) → порт. Цикл сработал как задуман.

## 3. Ядро: полный стек шага (все компоненты доказаны)

```
1.  Ритмы:        θ (5 рад/с), γ (40 рад/с); θ_mod[i] = sin(θ + 0.01·i)
2.  Стимуляция:   5% шагов → 1% нейронов +0.5
3.  Топология:    tgt(i,f) = (i·39293 + f·29101 + seed·73471) mod N
                  — связь существует как арифметика, 0 RAM на граф
4.  Синапсы:      v[tgt] += a·w·base·gain·(0.8 + 0.2·cos(phase + 0.3·θ_mod))
                  base: GABA·1.2 (тормозный) / глутамат·0.8 (возбуждающий)
                  gain: (1 + 2·NE)·(1 − 0.5·5HT)
5.  Инерция:      v += a·0.2·NE                       (EQ-A16)
6.  Активация:    a = max(0, tanh(v)·0.92 + N(0, 0.015) + b_tone)
7.  Торможение:   активный гасит соседей: exp(−|Δi|/(R/2))·0.1·a_pre,
                  R = N/100 («если сосед кричит — ты молчишь»)
8.  STDP+DA:      LTP сквозь дофаминовые ворота: w += 0.0003·DA
9.  Гомеостаз:    f_sys ← 0.99·f_sys + 0.01·act;
                  corr = (f_sys − 0.05)·0.02;
                  w>0 ×(1−corr); w<0 ×(1+corr); clip[−1, 1]
10. Тон:          b ← clip(b + 0.002·(0.05 − f_sys), 0, 0.25)   (F13)
11. Модуляторы:   DA (тренд), 5HT (дисперсия), NE (CV) — коридор [0.1, 0.9]
12. E/I:          спайковое E/I, мёртвая зона [2,6], GABA/глутамат ±0.01
```

**Золотые параметры** (не трогать без повторного доказательства):
homeo_k = 0.02, stdp_k = 0.0003, target = 5%, порог спайка 0.1,
шум σ = 0.015, спонтанная стимуляция 5%×1%, тормозных 20% (×−0.3),
R = N/100, мёртвая зона E/I [2,6], θ = 5 рад/с, γ = 40 рад/с,
k_b = 0.002, b_max = 0.25.

### 3.1 Что означает «здоровый мозг»

Активность ~5% с лавинными флуктуациями (std ≈ 0.04 — критичность,
край хаоса, как в биологических кортексах), синхронность S < 0.8,
E/I ≈ 4 (каноническое значение из исходных диалогов: стабилизация
4712/10000 нейронов, E/I = 3.85–3.92), нейромодуляторы в коридоре.
Это **не равновесие — это устойчивая динамика**: сеть живёт, шумит,
самоорганизуется. Полная противоположность эпилепсии (S → 1) и
смерти (activity → 0). В терминах исходных диалогов — «Сыфрофой»:
цифровая жизнь.

## 4. Модуль `src/ssn/`

| Файл | Суть | Доказательство |
|---|---|---|
| `rng.rs` | xoshiro256** (splitmix64-посев) — детерминизм без зависимостей | seed → траектория 1:1 |
| `cse.rs` | кодировщик текста: 16 бит-частот × золотая фаза, центрирование, нормировка | V8 + побитовый паритет с Python (cos = 0.9987 / −0.3547) |
| `mindos.rs` | NMDA-гейт, WTA, Bind, модуляция с затуханием | V9 |
| `vortex.rs` | полный стек шага (раздел 3) + телеметрия + readout + интроспекция весов | V17, F2/F8/F12/F13 |
| `transport.rs` | Кэли-транспорт (предвычисленная матрица), SCTP-проектор, спектральная норма степенной итерацией | V11/V13/V18 |
| `engine.rs` | оркестратор: inject_text (CSE→мозг), simulate, similarity | интеграционные тесты |

Тесты: **27 unit** (в т.ч. `parity_with_python_proof`,
`v17_invariants_two_seeds`, `inject_keeps_invariants`) +
`ssn_vortex_full_fidelity` (10 seed × 10k, `--ignored`, release)
+ MCP smoke (`ssn_tools_smoke_via_dispatch`). Весь репозиторий:
**1206 passed / 0 failed** + 21 Zig PND.

Производительность: 10k шагов × 600 нейронов × 16 полей за ~2.4 с
release (**~4200 шагов/с**) на i7-3770. Виртуальная топология даёт
масштабирование без RAM-штрафа: 100M синапсов < 1 ГБ (веса+фазы
8 Б/синапс, цели вычисляются на лету).

## 6. MCP-инструменты (для ИИ-агентов)

Резидентные живые мозги (LRU 8) — состояние живёт между вызовами:

| Инструмент | Назначение |
|---|---|
| `poler_ssn_step` | создать мозг (seed/n/fields/dims) или шагнуть существующий на steps шагов |
| `poler_ssn_inject` | сенсорная инъекция: text → CSE-вектор → активации → steps шагов |
| `poler_ssn_status` | снимок без шага: телеметрия + readout топ-K |
| `poler_ssn_eject` | выгрузить мозг (session=id \| all) |

Полный жизненный цикл: `poler_ssn_step {seed: 42, n: 600}` →
`poler_ssn_inject {session, text: "открыть терминал"}` →
`poler_ssn_status {session}` → `poler_ssn_eject {}`.

## 7. Место в архитектуре POLER

SSN — **субстрат управления** (слой S1): сенсорика (CSE) → живая
динамика (вихрь) → разреженный readout. Следующие слои строятся поверх:

- **S2 (следующий)**: readout → Motor-операторы MindOS → команды
  poler_exec (мозг управляет ОС: Windows/Linux/Mac/другие — исполнение
  уже абстрагировано E2-слоем);
- калибровка мухой: коннектом FLYCSR1 (C2) может стать морфологией
  вихря — реальные цепи вместо виртуальной топологии;
- литературный двигатель (L1) — специализированный наследник той же
  физики (Π_Λ, J-ротация, эхо): SSN обобщает его на произвольную
  сенсомоторную петлю.
