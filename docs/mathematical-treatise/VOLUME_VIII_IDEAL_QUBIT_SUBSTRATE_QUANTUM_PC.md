> Квантовый компьютер, который для задач до ~26 кубитов работает **точнее физических

## 1. Что такое «идеальный квантовый ПК» и почему он точнее физического

Физическая квантовая машина платит за каждую операцию:

| Источник ошибки | Физическая машина (2026) | POLER Quantum PC |
|---|---|---|
| Однокубитный гейт | fidelity ~1e-4…1e-3 | **0** (точная арифметика) |
| Двухкубитный гейт | fidelity ~1e-3…1e-2 | **0** |
| Считывание | ~1e-2…1e-3 | **0** (Born-семпл по точному CDF) |
| Декогеренция | T₂ ~ мкс–мс | отсутствует (нет среды) |
| Дрейф калибровок | суточные циклы | отсутствует (детерминизм xoshiro256++) |
| Округление арифметики | — (перекрывается физикой) | f64: 2.2e-16; **режим --exact: 0** |

Единственное, чем идеальный субстрат платит за точность, — память 2ⁿ и
классическое время: это машина для **точной науки и верификации**, а не для
квантового превосходства. Корпус POLER изначально строился как субстрат-матрица
(Том VII §2.3): здесь субстрат становится исполнимым инструментом.

**Компоненты** (крейт `pqc`, ноль внешних зависимостей):

| Модуль | Роль |
|---|---|
| `src/qpc.rs` | Circuit + QCASM-lite парсер + исполнение + измерение + отчёт (Landauer-пол) |
| `src/algorithms.rs` | QFT/IQFT, Grover (точный оракул), Bernstein–Vazirani, Deutsch–Jozsa, GHZ, Bell |
| `src/exact.rs` | Точное кольцо ℤ[1/√2, i]: бит-в-бит амплитуды Clifford+T |
| `src/substrate.rs` | P-поток УДЕ §2.2 с γ-прецесией и SCF (закрытые строки цикла G) |
| `src/bin/pqc.rs` | CLI: `pqc qc` / `pqc algo` / `pqc substrate` |

## 2. QCASM-lite

```text
qubits 3            # обязательна, первой
h 0                 # h|x|y|z|s|sdg|t|tdg q
ry 0 0.7853981633974483   # ry|rx|rz q θ
cx 0 1              # cx|cz|swap a b
ccx 0 1 2           # Тоффоли
cp 1 2 0.7853981633974483 # контролируемая фаза
flipphase 5         # фаза −1 на состояниях, где все биты маски 5 установлены
flipstate 22        # фаза −1 ровно на базисном состоянии |22⟩
flipzero            # фаза −1 на всех, кроме |0…0⟩ (диффузор Гровера)
measure 0           # измерение кубита (коллапс в per-shot режиме)
measure all
barrier
```

Конвенция битов — qiskit-совместимая: кубит 0 — младший бит индекса амплитуды.
Исполнение: если все измерения терминальные — один унитарный проход + N выстрелов
Борна; измерение до гейтов — честный per-shot режим с коллапсом
(обнуление невыигравших веток + перенормировка).

**Привилегия владельца вектора состояния:** физической машине оракул Гровера
приходится синтезировать из тысяч T-гейтов (каждый с ошибкой); идеальная машина
применяет фазовый предикат `flipstate`/`flipphase` **напрямую к амплитудам** —
о диффузоре `flipzero` тоже не надо синтезировать. Оракул становится точным
по определению.

## 3. Точное кольцо ℤ[1/√2, i] (режим `--exact`)

Амплитуды схем из {H, X, Y, Z, S, T, S†, T†, CX, CZ, SWAP, CCX, фазовые
оракулы} лежат в кольце

$$z = \frac{(a + b\sqrt{2}) + i\,(c + d\sqrt{2})}{2^k}, \qquad a,b,c,d \in \mathbb{Z},\ k \in \mathbb{N}.$$

Представление `ExactCx { a, b, c, d, k }` с i128-коэффициентами и проверкой
переполнения на каждой операции. Ключевые точные операции:

- **ω = 1/√2**: `(x + y√2)·√2 = 2y + x√2` → `a'=2b, b'=a, k+1` (на каждую часть);
- **T = e^{iπ/4} = (1+i)/√2**: сначала `(x+iy)(1+i) = (x−y)+i(x+y)`, затем ω;
- **S = i**: `re' = −im, im' = re`;
- **H**: `a' = ω(a+b), b' = ω(a−b)`.

Вероятности Борна — элементы ℤ[√2] с диадическим знаменателем:
$|z|^2 = \frac{a^2+2b^2+c^2+2d^2 + 2(ab+cd)\sqrt{2}}{2^{2k}}$ — читаются
как точные числа, а не приближения. Нормировка редуцируется сдвигом
общего множителя 2 (канонизация).

**Честные границы точного режима:**

1. Коллапс (mid-circuit measure) требует 1/√p — квадратичного расширения
   кольца; точный режим измеряет только терминально (семпл по f64-конверсии
   точного распределения).
2. Вращения Ry/Rx/Rz и CP(θ) при θ ∉ {π/2, π} вне кольца — отклоняются
   с диагностикой `NotExactGate` (QFT точен только до n=2; универсальность
   Clifford+T покрывает всё через синтез).
3. Глубина ограничена i128: сотни гейтов на амплитудный путь; переполнение
   детектируется (`ExactOverflow`), не молчит.

## 4. Квантовый субстрат УДЕ (цикл G: две открытые строки Тома VII закрыты)

Том VII §6.5 оставлял открытым включение γ > 0 (прецессия занятого
подространства) и SCF-режим. Оба исполнены в `substrate.rs`:

$$P_{t+1} = \mathcal{Q}\Big(P_t - \eta\,[P_t,[P_t,F]] + \eta\gamma\,[F,P_t] + \mu\tfrac{N-\mathrm{Tr}\,P_t}{n}\mathbf{I}\Big),\qquad \mathcal{Q}(X)=3X^2-2X^3.$$

**Thm G.1 (роторная работа).** За шаг роторная добавка совершает работу
$$\Delta E_{\mathrm{rot}} = \eta\gamma\,\mathrm{Re}\,\mathrm{Tr}\big([H,F]\,P\big).$$
При F = H (фиксированный фокиан) она **тождественно нулевая**: [H,H] = 0 —
прецессия вращает траекторию, не меняя энергии. При F = F[P] ≠ H (SCF,
F = H + U·diag(diag P)) ротор качает энергию через самосогласованное поле.
*Верифицировано: γ=0.5, F=H — суммарная |работа| = 0.0 (точно, 400 шагов);
SCF U=0.8, γ=0.3 — |работа| = 1.416e-1 (NumPy-реплика 8.0e-15).* ∎

**Thm G.2 (прецессия сохраняет сходимость).** При γ ≤ 0.5, F = H итерация
§2.2 сходится к проектору Ауфбау: дефект идемпотентности 3.2e-16, след
восстановлен химическим потенциалом точно (Thm F.8 + §2.1-Шаг 4 Тома VII). ∎

**Thm G.3 (дискретная монотонность — честная форма).** Сертификат Ляпунова
$dE/d\tau = -\|[H,P]\|^2_{HS} \le 0$ (Thm F.8b) гарантирует монотонность
**потока**; дискретная итерация с квантователем МакВини допускает
транзитные подъёмы энергии в фазе выравнивания — измерено ≤ 9 из 400 шагов
(≤ 3%) при η = 0.05 с чистым спуском энергии от старта к фикспоинту.
Квантователь = измерение (Том VII §4): подъёмы локализованы там, где он
«решает» собственные значения. ∎

**SCF-режим:** F[P] = H + U·diag(Re diag P) — хаббардовское среднее поле;
фокиан пересобирается на каждом шаге, самосогласованность сходится
(финальная невязка ‖F[P]−F_prev‖ = 6.2e-10 при U = 0.8, 600 шагов).

## 6. Честные ограничения инструмента

1. **Память 2ⁿ:** потолок движка 26 кубитов (1 GiB амплитуд); это не «предел
   науки», а граница statevector-класса. Tensor-network/симуляция схем с малой
   запутанностью — открытая строка (не претендует).
2. **Нет квантового ускорения по времени:** идеальный субстрат экспоненциально
   дорог по классической природе; его ниша — точность и воспроизводимость,
   а не масштаб.
3. **Точное кольцо ≠ вся квантовая механика:** произвольные углы (QFT при
   n > 2, VQE-анзацы) остаются в f64; кольцо покрывает Clifford+T-универс
   через синтез (с экспоненциальным ростом T-гейтов).
4. **Субстрат — маленькие гильбертовы пространства:** dim ≤ 16 (плотные
   матрицы O(n³) на шаг); большой химический субстрат требует sparse/CI-методов.
5. **Стриб-монотонность**: см. Thm G.3 — квантователь покупает квадратичное
   дробление ценой ограниченных транзитных подъёмов энергии.

### 8.1 Теоретико-числовой субстрат: поиск периода (Том VII §2.3, строка 5)

Инстанциация «фазовые вращения a^x» получила исполнение:

* **Op::PrepComb** — гребёнка |ψ⟩ = (1/√m)Σ_j|offset + j·r⟩: состояние
  после оракула модульного возведения в степень. Привилегия владельца
  вектора состояния (как оракул Гровера): идеальная машина не платит за
  синтез modexp. В точном кольце зубья 1/√m живут ⟺ m = N/r — степень
  двойки (честный отказ иначе — как Ry вне {0, π/2, π}).
* **period_finding** — QFT с явным бит-реверсом (истинная конвенция
  |x⟩ → Σω^{xk}|k⟩/√N; вывод конвенции — покомпонентная проверка на n=2)
  + MeasureAll. Аналитика Дирихле |QFT|ψ⟩|²(k) = sin²(mθ/2)/(mN·sin²(θ/2)),
  θ = 2πkr/N — движок совпадает по ВСЕМ k до 1e-16 (тест
  `period_finding_dirichlet_parity`).
* **Восстановление периода**: r = min{q ≥ 2 : каждый пик k даёт k·q/N
  близко к целому} (допуск q/N покрывает квантование ±1/2 и главный
  лепесток 1/(2m)). Доказуемо точно при 1.5·r² < N; за границей —
  эвристика Шора (r = 12 при N = 64 — эмпирически подтверждено).
* **Замкнутый цикл «квант → SMT»** (цикл H): движок восстанавливает
  ord_N(a) для (N,a) ∈ {(15,2),(15,7),(21,2),(35,2),(35,6)}; Z3
  сертифицирует a^r ≡ 1 и минимальность (∀k<r: a^k ≢ 1). Криптография
  разложила бы N по найденному периоду; здесь N полупростые нарочно —
  продемонстрирован САМ механизм, а не взлом.

### 8.2 Крипто-субстрат: SMT (Том VII §6.5, строка 6 — закрыта)

Слоёная стратегия: прямой BV-миттер φ⁻¹(φ(x)) = x с цепочечными
умножителями (x·C)·C⁻¹ неразрешим бит-бластингом (эквивалентность
мультипликаторов экспоненциальна для резолюции — Bryant 1991; timeout
240 с задокументирован). Решение: (1) Bézout-сертификат C₂·D = 1+m·2³²;
(2) мультипликативное ядро в Int-арифметике — умножение на константу
ЛИНЕЙНО, Z3 proved мгновенно; (3) линейные оболочки S₁/S₂ — BV-миттеры;
(4) мост — сдвигово-аддитивное разложение x·C (64 схемных значения +
дистрибутивность). S-box x^254: миттер QF_BV 0.1 с (после исправления
цепочки x^255→x^254 — баг пойман Z3-контрпримером, «контрпример: []»),
биективность — 256 схемных вычислений. H.10: равномерность — неподвижная
точка раунда (крипто-инстанциация Thm F.7(a)).

Инженерная находка цикла: DAG-обход Z3-выражений в Python требует
мемоизации по get_id() — дерево gf_mul-схемы экспоненциально (168 узлов
DAG = 803 617 узлов дерева; ядро Z3 работает с DAG нативно).

### 8.3 Gottesman–Knill: за пределами 26 кубитов (строка 2 директивы)

`crates/pqc/src/stabilizer.rs` — stab-only архитектура (без
дестабилизаторов): n генераторов (x, z, r ∈ Z₄) в конвенции
P = i^r·X^x Z^z (покубитно X до Z — односторонняя симплектика
P₁P₂ = (−1)^{⟨z₁,x₂⟩}P(xor)). Фазовые правила гейтов выведены
алгебраически (S: x_q=1 → z_q⊕=1, r+=1 — проверено на Y-строках);
CZ — канонической декомпозицией h·cx·h (рукописные правила CZ
фазо-рискованны).

* Измерение Z_q: антикоммутация ⟹ Борн ровно ½; иначе GF(2)-исключение
  [X|Z|I] с identity-трекингом собирает ±Z_q из генераторов (фаза = искомое
  собственное значение). RREF-кэш амортизирует детерминированные запросы;
  случайное событие инвалидирует (честно задокументированный worst case).
* Точные ⟨Z_S⟩ ∈ {0, ±1} (спектральная теорема) — против qiskit: 2.2e-16
  на GHZ-8 и кластере-10 (цикл I).
* Масштаб: GHZ-2048 ≈ 0.7 с; GHZ-1024 ≈ 93 мс; случайные Клиффорды на
  512 с измерением — секунды. Память n·n/4 байт: 16 384 кубита ≈ 64 МБ
  (statevector на 27+ кубитах — терабайты).

### 8.4 Шумовые модели: «идеал vs железо» (строка 3 директивы)

`crates/pqc/src/noise.rs` — квантовые траектории поверх statevector:
деполяризация (сэмпл Паули), амплитудное затухание (точный MCWF: прыжок
K₁ с вероятностью γ·⟨1_q⟩, иначе K₀×√(1−γ) + normalize), фазовое затухание
(Tφ из T1/T2), чтение (симметричный флип). Оракулы-привилегии шумом не
поражаются — синтез владельца, не физический гейт (граница модели).

Пресеты: ibm-heron (2Q 8e-3), google-willow (2Q 4e-3), noisy-90s (6e-2).
Grover-6: идеал 99.7% → heron 88.7% → willow 84.7% → 90-е 32.4% —
количественный контраст директиве «точнее физических кубитов».

**Найдено и закрыто сверкой с qiskit-Kraus**: no-jump-ветвь MCWF вшивала
глобальный фактор выживания 1/√(1−γp₁) только в |1⟩-строки — искажение
ОТНОШЕНИЯ амплитуд (0.5813 vs точные 0.6484). После фикса: движок 0.6484
= qiskit 0.648437. Дважды за цикл независимый арбитр поймал мою ошибку
(второй раз — моя формула P(00): пары XY/YX тоже сохраняют носитель;
правильно P(00) = ¼(1+(1−4p/3)²) по Блоху).
