# LITERARY.md — Литературный Двигатель POLER[Ψ] (L1/v0.34.0)

**Физика смысла для ИИ-агентов: нарратив как динамическая система.**
Полная матричная форма канонического уравнения POLER[Ψ], калиброванная
живым мозгом мухи FlyWire v783. Это руководство — как допрашивать поле
замысла, вести нарратив шаг за шагом и читать телеметрию H^Ψ.

```
src/literary/
├── linalg.rs      плотная f32-алгебра (Холецкий, Гаусс—Жордан, ноль зависимостей)
├── qualia.rs      ℘ Перцепция: текст → Ω(o) (FNV-хэш, ноль RNG) + 12 архетипов
├── projector.rs   L Логика: Π_Λ = I − J_cᵀ(J_cJ_cᵀ)⁻¹J_c — аннигиляция галлюцинаций
├── echo.rs        R[n] Резонанс: темпоральное эхо Σ ρᵏ·p_{t−k}, ρ = 0.9
├── prism.rs       «No Excuses»: преломление тупиков, точное сохранение энергии
├── trit.rs        Trit5/No-Mul: p_t → {−1, 0, +1}, SIMD-скалярные произведения
├── flybridge.rs   мост на муху: каста нейронов → J = A − Aᵀ (циркуляция смыслов),
│                  D = L·Lᵀ (метрика Ляпунова), драматургические пары
└── engine.rs      Ψ Интенция: канонический интегратор + генерация нарратива
```

## 1. Что это такое

Обычный LLM — стохастический предсказатель токена. Литературный Двигатель —
**детерминированная механика смысла**: замысел (текст) превращается в
инвариантный вектор Ω(o) на единичной сфере фазового пространства, и дальше
система эволюционирует по каноническому уравнению к когнитивному покою
H^Ψ = 0 — «информационной сверхпроводимости», где градиентный поток замысла
не встречает сопротивления.

Пятифазный цикл ℘–O–L–ε–R[n]–Ψ:

| Фаза | Что происходит | Где в коде |
|---|---|---|
| ℘ Перцепция | текст → Ω(o): каждый терм хэшируется FNV-1a64 в ось, вклад = редкость; ‖Ω‖ = 1 — энергия замысла фиксирована | `qualia::perceive` |
| O Образ | косинусная топология против 12 якорей архетипов (путь героя Кэмпбелла + Наблюдатель/Призма/Сверхпроводимость канона POLER) | `qualia::cosine_topology` |
| L Логика | проектор причинности Π_Λ: компоненты, нарушающие законы вида pᵢ − pⱼ = 0, аннигилируются математически — у галлюцинаций нет направления | `projector::CausalProjector` |
| ε Энергия | «смысловое удивление» = расстояние состояния от эха; пластичность 0.2·ε — при новом система деформируется смелее | `echo::surprise`, `engine` |
| R[n] Резонанс | память = Σ ρᵏ·p_{t−k}: нить повествования через интеграл состояний, а не объём окна | `echo::TemporalEcho` |
| Ψ Интенция | H^Ψ → 0 = Observer-Kill (субъективные искажения гасятся) → сверхпроводимость | `engine::PsiMode` |

Канонический интегратор (одно уравнение — весь движок):

```
p_{t+1} = p_t − η_eff·Π_Λ(∇F + D·p_t + γJ·p_t) + η_r·Π_Λ(κ·(echo_t − p_t))

∇F  = 2(p − Ω(o)) + 2λ·J_cᵀ(J_c·p)        — притяжение замысла + логическая регуляризация
D·p  = B·(L·Lᵀ)·Bᵀ·p + p                   — диссипация Ляпунова, калиброванная мухой
γJ·p = γ·B·(A−Aᵀ)·Bᵀ·p                      — циркуляция смыслов: ротор живого мозга
echo = Σ ρᵏ·p_{t−k} / Σ ρᵏ                  — резонансная тяга (градиент ε)
η_eff = η·(1 + 0.2·ε)/(1 + Σ(t))           — пластичность ↑, фазовая инерция ↓
```

Гиперпараметры (манифест): η = 0.1, η_r = 0.05, ρ = 0.9, κ = 1.2,
γ = 1.0, λ = 10⁻². Все переопределяются в CLI/MCP.

## 2. Зачем агенту

1. **Анализ замысла без потерь** — `poler_literary_field` раскладывает текст
   на термы-инварианты и архетипы детерминированно: тот же текст — то же
   поле, побитово. Никакого эмбеддера, никакого API.
2. **Ведение нарратива шаг за шагом** — `poler_literary_step` держит
   резидентную сессию: состояние, эхо и каустика живут в RAM между
   вызовами. Эволюция замысла = аргумент `observation`.
3. **Генерация с телеметрией** — `poler_literary_generate` прогоняет
   траекторию до покоя и отдаёт три акта (доминанты-архетипы, кривую F),
   конфликты и инженерный отчёт: F, ε, Σ(t), H^Ψ, причинность.
4. **Муха как соавтор** — с `csr` ротор J = A − Aᵀ реального мозга
   закручивает поле: нарратив не замерзает в аттракторе, а живёт в
   предельном цикле. Драматургические конфликты = роторные пары нейронов.

## 3. MCP-инструменты (4)

### 3.1. poler_literary_field — анализ поля (℘→O)

```json
{"text": "герой идёт в поход против тьмы и бездны, наставник даёт совет"}
```

Опционально: `dims` (16–256, умолч. 64), `constraints` (массив {i, j, c}),
мушиная калибровка `csr` + `nodes` + `seeds` (до 16, индексы или root_id,
умолч. [0]) + `khop` (1–4, умолч. 2) + `max_cast` (2–64, умолч. 48).

Ответ: токены/термы по массе, топ-6 архетипов по косинусу, F₀
(≈ ‖Ω(o)‖² = 1 для непустого замысла), остаток причинности; при калибровке —
секция `fly`: размер касты, BFS-охват, внутренние рёбра/масса, топ-ротор.

### 3.2. poler_literary_step — резидентный полигон фазы

Создать сессию (stateless → stateful):

```json
{"text": "бунт против шторма, огонь и свобода", "no_mul": true}
```

Шагнуть существующую (эволюция замысла через observation):

```json
{"session": "psi-3-a1b2", "observation": "тишина зимнего сада и покой"}
```

Ответ — телеметрия шага: `f_free, epsilon, sigma_t, resonance_norm,
phase_inertia, causality_residual, plasticity, h_psi, mode, refractions`.
Режимы: `attraction` → `refraction` (тупик, призма включилась) →
`observer_kill` (субъективное эхо подавлено) → `superconductivity` (покой).

Сессии: LRU, максимум 8 (агент ведёт несколько нарративов параллельно);
`poler_literary_eject` (`session` или `all`) — выгрузка из RAM.

### 3.3. poler_literary_generate — генерация нарратива

```json
{"text": "герой идёт в поход против тьмы и бездны",
 "csr": "docs/flywire-connectome/flywire_v783_core.csr.zst", "seeds": [0]}
```

Или на резидентной сессии: `{"session": "psi-3-a1b2"}`.

Ответ: `converged` (достигнута ли сверхпроводимость), `f_final`,
`h_psi_final`, `causality_clean`, три акта (`dominants` — топ-3 архетипа
по косинусу снапшота состояния), `dramatic_pairs` (мушиные конфликты),
сжатая `timeline` и `text` — детерминированная разметка нарратива
(поле → траектория → конфликты → телеметрия; не стохастический генератор,
а расчётный каркас для автора).

**Два режима физики:**
- **Без мухи** — чистая физика текста: F падает до ~1e-5, сходимость за
  33–45 шагов, режим сверхпроводимости.
- **С мухой** (csr) — предельный цикл: F оседает на плато ≈ 0.26 (от
  касты зависит), converged = false. **Живой мозг не даёт нарративу
  замереть** — циркуляция J поддерживает вечное движение вокруг аттрактора.
  Это фича, а не ошибка: трактовка «живости» против «кристалла».

### 3.4. poler_literary_eject — выгрузка сессий

```json
{"session": "all"}
```

## 4. CLI

```bash
# Анализ поля
poler-engine --literary-field "текст замысла" [--literary-dims 128] [--literary-json]

# Генерация (без мухи — сходимость)
poler-engine --literary-generate "текст замысла" [--literary-steps 128]

# Генерация с мушиной калибровкой (предельный цикл + конфликты)
poler-engine --literary-generate "текст замысла" \
  --literary-csr docs/flywire-connectome/flywire_v783_core.csr.zst \
  --literary-nodes docs/flywire-connectome/flywire_v783_nodes.bin \
  --literary-seeds 0,116214 --literary-khop 2 --literary-max-cast 32

# No-Mul: троичная решётка Trit5 (SIMD-резонанс)
poler-engine --literary-generate "текст" --literary-no-mul

# Гиперпараметры: --literary-eta/--literary-eta-r/--literary-rho/
#   --literary-kappa/--literary-gamma/--literary-lambda
```

## 5. Мушиная калибровка: как именно муха участвует

`flybridge::build_cast(con, seeds, khop, max_cast)`:

1. **BFS** от семян по всем связям (khop шагов, до 4) — кандидатская каста.
   От нейрона 0 на khop=2 достигается 457 нейронов (фронты C2: [13, 443]).
2. **Жадный детерминированный отбор** до max_m: семена всегда; прочие —
   по (хоп ↑, максимальный вес ребра к уже выбранным ↓, индекс ↑).
   Повторный запуск даёт побитово ту же касту.
3. **Induced-подграф** A_sub (только рёбра между членами) → ротор
   J_sub = A_sub − A_subᵀ (кто доминирует над кем внутри касты).
4. **Метрика Ляпунова** G = I + β·sym(|J_sub|), β адаптивно: строгое
   диагональное доминирование (Гершгорин) ⇒ SPD на любом коннектоме;
   L = chol(G), D = L·Lᵀ.
5. **Проекция в архетипное поле**: якорь нейрона = FNV(root_id) mod 12;
   матрица связи B собирает касту в 64 оси; J_lit = B·J_sub·Bᵀ
   (антисимметрична), D_lit = I + B·D·Bᵀ (SPD). Циркуляция нормируется
   (max|J_lit| = 1) — устойчивость Эйлерова шага не зависит от масштаба
   синаптических масс.
6. **Драматургические пары**: топ циркуляций J_lit отображается обратно в
   пары нейронов (дедуп ориентацией «J > 0 эмитит» — конвенция rotor_top C2).

Золотые числа (ядро v783, seeds [0], khop 2, max_cast 48):
каста 48 нейронов, 252 внутренних ребра, масса 4345; топ-ротор касты
J[31552][80928] = +197; нагрузка архетипов [6,4,5,2,6,4,2,2,2,5,6,4];
топ-конфликт — 13609 [Тишина] доминирует над 41414 [Сверхпроводимость].

## 6. Принцип «No Excuses» и призма

Если F растёт 3 шага подряд — семантический тупик. Энергия смысла не может
исчезнуть (Закон Сохранения Смысла): заблокированная компонента обновления
**переизлучается** внутри разрешённого подпространства вдоль ближайшего
архетипа (Householder-поворот с реортогонализацией). Итог: ‖r‖ = ‖v‖ с
точностью f32-эпсилон и J_c·r = 0 — причинность чиста, энергия сохранена.
Режимы: `Direct` (путь свободен) / `Refraction` (преломление в архетип) /
`TotalInternal` (все оси отвергли — детерминированная подстановка формы).
Отказа от генерации не существует в принципе.

## 7. Trit5 / No-Mul

`--literary-no-mul` / `"no_mul": true`: после каждого шага латентное
состояние раунд-трипится через троичную решётку {−1, 0, +1} (кодек Trit5
из pqc, 5 тритов на байт, per-vector масштаб + мёртвая зона 5%).
Скалярные произведения с эхом считаются AVX2-кернелом `dot_trit5_f32`
без f32-умножений. Плата: предельный цикл расширяется (F ≈ 1.6 против
0.26 у f32 на мухе) — троичная решётка груба, цикл остаётся ограниченным.

## 8. Производительность (release, i7-3770)

| Операция | Время |
|---|---|
| field без мухи (64 оси) | < 1 мс |
| generate без мухи (48 шагов) | ~2 мс |
| Каста 48 нейронов (BFS+induced+Холецкий), тёплый артефакт | ~10 мс |
| generate с мухой (48 шагов + каста) | ~20 мс |
| MCP-конвейер 7 запросов (field+step+generate×2+eject, внеочерёдно) | ~0.03 с |

Коннектом грузится один раз (WarmFly, переиспользуется с poler_fly_*),
сессии живут в RAM (LRU 8), семейство исполняется в пуле воркеров.

## 9. Стратегия допроса для агента

1. `poler_literary_field` — понять инвариант: термы по массе, архетипы.
2. Решить физику: чистая сходимость (без csr) или живой цикл (с csr).
   Для «души» текста — цикл; для «кристалла» — сходимость.
3. `poler_literary_step` — вести нарратив: observation = развитие замысла,
   следить за ε (новизна) и Σ(t) (инерция души: рост — шаг затухает).
4. `poler_literary_generate` — финализировать: акты, конфликты, H^Ψ.
5. Читать конфликты буквально: «13609 [Тишина] доминирует над
   41414 [Сверхпроводимость], J = +1» — архетипы с силой доминирования.
6. `poler_literary_eject` — убрать за собой.

## 10. Верификация

- Синтетика: идемпотентность Π, самосопряжённость, замкнутая форма эха
  (Σ ρᵢ), сохранение нормы призмой с точностью 1e-4, раунд-трип Trit5.
- Золото v783: каста 48/457/252/4345; чистый движок — converged, F < 1e-4;
  муха — цикл F = 0.2572 ± 5e-3, причинность чиста, 0 преломлений.
- Полный счёт: **1238/1238** pnd-ffi (+46), **1176/1176** default (+46),
  21/21 Zig; 0 предупреждений в обоих конфигах.
