# ЧОМУ МИ ВІДМОВЛЯЄМОСЯ ВІД СТАТИЧНИХ "ЖИВИХ ВАГ" ТРАНСФОРМЕРІВ (GLM 6B) НА КОРИСТЬ НАВЧАЛЬНОГО JIT-КОНТУРУ

> **Дата рішення:** 18 вересня 2026 р.  
> **Статус:** Архітектурний перехід від статичного Transformer Inference до динамічної JIT-Пластичності (Cerebellum / Hebbian STDP Loop).

---

## 1. СУТЬ ЕКСПЕРИМЕНТУ ТА ПРИЧИНА ВІДМОВИ

Ми успішно зібрали, квантували в Int4/Trit5 та верифікували повний інференс 6.2-мільярдної моделі `ChatGLM3-6B` на чистому Rust без Python, PyTorch чи GPU:
- **Точність ваг:** косинусна схожість `0.987` (ідеальне квантування).
- **Семантика:** Half-Rotary RoPE повністю відновлений, модель генерує осмислений текст.
- **Розмір:** 3.0 ГБ на диску (`chatglm3-6b-int4.pqw`).

**Але класичний підхід Transformer Inference виявився глухим кутом для реального часу:**

1. **Memory Wall & Обчислювальна затримка на CPU**:
   - 6.2 мільярда параметрів у 28 шарах вимагають послідовного обчислення 28 разів для *кожного окремого токена*.
   - Швидкість генерації на процесорі (Intel Core i7) складає **~1.6 токена/сек** (25–28 секунд на коротке речення).
   - Для інтерактивної роботи та миттєвого відгуку системи це занадто повільно.

2. **Статичність класичних ваг**:
   - Класичні ваги трансформера — це "мертва застигла пам'ять". 
   - Вони не здатні самостійно еволюціонувати в реальному часі без гігабайтних градієнтів та бекпропагейшну.

## 2. НОВИЙ ШЛЯХ: НАВЧАЛЬНИЙ JIT-КОНТУР (ВЕСИ = МАШИННИЙ КОД)

Замість того, щоб ганяти гігабайти статичних матриць через повільні цикли декодера, ми переходимо на форму прямого машинного навчання:

| Критерій | Статичний LLM-декодер (6B) | Наш Навчальний JIT-Контур (`jit_loop`) |
|---|---|---|
| **Затримка (Latency)** | 25 000 – 30 000 мс | **0.1 – 10 мс (в 3000 разів швидше)** |
| **Принцип роботи** | Послідовний перебір 28 шарів матриць | Прямі апаратні інструкції CPU (x86_64 ASM) |
| **Множення** | Мільярди операцій FP/INT MAC | **No-Mul (тільки + та - для Trit5)** |
| **Пластичність** | 0% (ваги застиглі) | **100% Hebbian STDP + ротор $J = A - A^T$** |
| **Самомодифікація** | Неможлива без GPU-кластера | Код сам перекомпілює власні біти на льоту |
