# Game Cycle T Benchmarks — v0.55.0 (2026-09-22)

> Методика: release-сборка (`cargo build --release`), живой бинарник
> `./target/release/poler-engine --shell` (команды `game sound`,
> `game texture`), машина sandbox 2 vCPU / 4 GiB RAM.
> Все хеши — FNV-1a, детерминизм бит-в-бит проверяется двойным прогоном.

  175.8 Гц (F3+12c) — интервалы порождены кеплеровскими ω сцены.

  потолок 0.95 держится (тест sonify_sounds_and_limiter_holds).
