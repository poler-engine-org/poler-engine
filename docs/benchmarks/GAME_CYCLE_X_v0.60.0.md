# Цикл X «Обрушение» — нелинейная гидродинамика на целочисленном кремнии (v0.60.0)

Дата: 2026-09-24 · задание владельца: «нелинейное вихревое растяжение +
обрушение гребней (то, что OpenAI brute-force'или)» — первый пункт из трёх
(дальше: BVH-коллизии, VRTX-пейлоады в .poler).

## 1. Физика цикла (всё честно, без магии)

| Явление | Уравнение | Реализация |
|---|---|---|
| Стокс, 2-й порядок | h₂ = (kA²/2)·cos 2θ — гребень острее, ложбина площе | каноничные вторые гармоники ±2k в собственной лог-шкале контейнера (окно вторых гармоник) |
| Сдвиг частоты Стокса | ω·(1 + (kA)²/2) | в том же целочисленном счётчике фаз — та же целочисленность, без дрейфа |
| Лимит Мичелла (спиллинг) | k·A > s_b → срез до 0.9·s_b | событие с кулдауном 3 периода; энергия события — бухгалтерски: когерентный вихрь + тепло |
| Белые барашки (Бофорт) | первые ≈ 9 м/с; частота ∝ (v−v₀)² | наблюдательный триггер как source-term диссипации; фикс-точечный аккумулятор долей событий |
| Вихрь Ламб–Озеена | ядро r² = r₀² + 8νt | вязкое расплывание на фикс-точке |
| Растяжение вихря | dΓ/dt = Γ·∂u/∂x | клип ±0.25/шаг, потолок 2·Γ₀ |
| Дрейф Стокса | u_s = ω·A²·k/2 | НЕТ отдельного члена — возникает сам из лагранжевой адвекции вихря полем волн |
| Поверхностный след | Δh = Γ²/(4π²·g·r²)·e^(−d²/2r²) | горб напора скорости ядра; FFT-штампы + аналитика surface_at |
| Ротационное поле | ∮u·dl = Γ·(1 − e^(−R²/r²)) | `flow_full_at` — ПЕРВОЕ ротационное поле движка (теорема Стокса — тест меряет) |

## 2. Бухгалтерия энергии (баг, пойманный тестом)

Тест `whitecap_event_energy_conserved` вскрыл реальный дефект: `pay_from_modes`
списывал с мод целевую энергию события, но clamp аккумулятора на нуле мог
не дать модам расплатиться — а вихрь и тепло получали полную сумму.
**13.6% фантомной энергии** «из ниоткуда». Исправление: сбор событий теперь
возвращает ФАКТИЧЕСКИ уплаченное (измеримо по тем же уровням лестницы, что
читает `variance()`), размер барашка честно уменьшается, если море бедно:
`ΔE_мод = Σ E_вихрей + Δтепло` — тождество, тест закрывает с допуском 1%.

Чтение: до 12 м/с море точное по Пирсону–Московицу и барашков нет (кумулятор
долей ещё не набрал первое событие — честная дискретизация). С 16 м/с —
лавинный рост событий ×2.5 на ступень Бофорта; диссипация обрушения подавляет
развитие молодого моря (79% → 62% от PM) — физично: PM предполагает часы
развития, здесь 30 с. PSNR против f64-эталона падает с ростом шторма —
честная цена дискретных событий против непрерывной релаксации зеркала.
