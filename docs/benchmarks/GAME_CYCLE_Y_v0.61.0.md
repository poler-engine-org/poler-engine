# Цикл Y «Эхо» — нейронное квантование готовых ассетов (v0.61.0)

Дата: 2026-09-24 · задание владельца: «готовые звуки/ассеты квантуются в наш
PQW через нейросеть — нейроны, синапсы, всё уже в проекте. Готовое не значит
взять как есть: оно ГЕНЕРИРУЕТСЯ С НУЛЯ поверх готового». Готовый ассет —
не файл рядом с движком, а УЧИТЕЛЬ: движок впитывает его структуру и поёт сам.

## 1. Архитектура (всё уже было в проекте — связано воедино)

```text
готовый ассет (WAV/PNG/PGM/PPM на диске)
  1. контейнеры — СВОИ: WAV-PCM16-ридер, PNG + inflate RFC 1951
     (stored/fixed/dynamic Huffman, анфильтр Paeth), PGM/PPM
  2. НЕЙРОНЫ: полосные нейроны спектра (звук, 24 полосы STFT 1024/512)
     / прототипы тайлов (текстура, WTA-кодбук 32×16²)
  3. СИНАПСЫ: STDP-граф лаг-1 корреляций полос — асимметрия = направление
     времени (кто fires раньше); граф смежности тайлов (Хебб по растру)
  4. PQW .poler: дуги графа = топология, параметры = трит+σ (ошибка ≤ 1/126),
     гипер-параметры = глобалы (fs/размеры/стерео-ρ/уровень)
  5. EMIT с нуля: SSN-вихрь 600 нейронов (доказанный режим: критичность,
     лавины) рождает ТАЙМИГ обрушений; синапты — спектральную связность
     (когерентные всплески полос); случайные фазы + OLA — реализация
```

| Слой | Источник в проекте | Роль в «Эхе» |
|---|---|---|
| SSN «Синаптический Вихрь» (src/ssn) | 226 уравнений, 65/65 проверок | живой мозг: тайминг обрушений (лавины при критичности) |
| Trit5-кристалл (src/triune) | синапсы {−1,0,+1}, стрим-квантование 1.67 бит/вес | философия трит-квантования весов |
| PQW (crates/pqw) | фазовые состояния POLER[Ψ], трит+кривизна σ | контейнер: ассет как фазовое состояние |
| FFT T1 (src/game/audio) | собственный радикс-2 | STFT абсорба и синтеза |
| SVD T2 (src/game/texture) | односторонний Якоби | кодбук в базисе сингулярных векторов |

## 2. Честность метрик

Регенерация — ДРУГАЯ реализация тех же статистик (вторая волна в том же
море), поэтому:

- звук: сэмпл-точный PSNR не определён — меряется **PSD-дистанция по 24
  полосам** (дБ), каденс модуляции, стерео-корреляция, детерминизм бит-в-бит;
- текстура: PSNR против оригинала при той же решётке (блуждание по графу
  даёт НОВУЮ раскладку тайлов) + гистограммная дистанция (64 бина, L1/2);
- контейнер меньше входа на порядки, но это НЕ сжатие данных: это
  статистическая модель — «понимание» звука/текстуры, из которой можно
  сгенерировать сколь угодно много.

## 3. Эксперименты (release, 0.61.0)

Входы сгенерированы Python'ом (роль «внешнего мира» — как скачанные ассеты);
на машине владельца: `ffmpeg -i ocean_real.ogg ocean_ready.wav` → тот же путь.

### Звук: 10 с океана → 2 075 байт → 60 с с нуля

| Метрика | Значение |
|---|---|
| Вход | ocean_ready.wav, 10.0 c, 48 кГц, PCM16 stereo, 1 920 044 Б |
| Контейнер | **ocean.pqw — 2 075 Б (×925 против PCM)**, 24 мс абсорба |
| Нейроны/синапсы | 24 полосных · **529 STDP-дуг** · каденс **0.73 Гц** (задан 1/1.35 — извлечён) |
| Регенерация | **60.0 c** (в 6 раз длиннее входа) за 4.1 с, 11 250 шагов вихря |
| Мозг | 600 нейронов · 5 978 лавин · активность 1.5% · критичность 0.63 |
| PSD-дистанция | **1.39 дБ** (24 полосы, против входа) |
| Детерминизм | двойной emit — WAV **бит-в-бит** (0x022D547077C54A94), seed из digest контейнера |

## 5. Шелл

```
poler-engine game asset absorb --in ocean_ready.wav --out ocean.pqw [--json]
poler-engine game asset emit --in ocean.pqw --out ocean.wav \
    [--seconds 30] [--seed N] [--burst 0..8] [--compare ORIGINAL] [--json]
poler-engine game asset absorb --in foam.png --out foam.pqw
poler-engine game asset emit --in foam.pqw --out foam_512.png \
    [--width 512 --height 512] [--compare foam.png]
```

Формат входов: WAV PCM16/float32 (любые каналы), PNG 8-bit gray/RGB (любые
фильтры, свой inflate), PGM/PGM P5/P6. OGG/JPEG — конвертация одной командой
ffmpeg/magick на машине владельца (контейнер ≠ вычисление).

## 6. Демо Panda3D

На машине владельца: `ffmpeg -i ocean_real.ogg ocean_ready.wav`, затем
