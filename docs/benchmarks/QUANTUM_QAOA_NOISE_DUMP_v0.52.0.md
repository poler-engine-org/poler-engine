## 1. Что вошло в цикл Q (v0.52.0)

| Фронт | Команда | Суть |
|---|---|---|
| QCASM из шелла | `quantum qcasm <файл\|->` / `quantum run qcasm …` | произвольные схемы: statevector, `--exact` (кольцо ℤ[1/√2, i]), `--noise` |
| QAOA | `quantum qaoa [--edges] [--p]` | MaxCut-ансатц: cost-слой CX·Rz(−γ)·CX, mixer Rx(2β), координатный спуск с перезапусками, E[cut] считается точно по вектору состояния |
| Шум поверх верификатора | `quantum verify … --noise <пресет> --shots` | вердикт (доказано/опровержено) + деградация на железе: TVD, F_класс, χ² Пирсона, пик |
| MCP | `poler_quantum`: `qcasm`, `qaoa`, `verify.noise` | все три фронта доступны ИИ-агентам через stdio/HTTP |
| CLI pqc | `pqc qaoa [opts]` | автономный бинарь (1.6 МБ) |

## 3. QAOA: MaxCut (вся оптимизация + финальный прогон)

| Граф | p | evals E[cut] | E[cut] init → opt | лучший разрез | отношение | время |
|---|---|---|---|---|---|---|
| треугольник (3v/3e) | 2 | 388 | 1.74 → **2.000** | 2/2 | **100%** | 0.41 с |
| демо 4-цикл+диагональ (4v/5e) | 2 | 243 | 2.50 → **4.00** | 4/4 | **100%** | 0.61 с |
| K6 (6v/15e) | 3 | 363 | 5.89 → **8.94** | 9/9 | **100%** | 2.1 с |
| сетка 3×3 (9v/12e) | 2 | 243 | 5.84 → **6.85** | 12/12 | **100%** | 0.9 с |

Замечания:
* Инициализация (E[cut] init) — это эвристическое расписание углов до спуска;
  случайное назначение дало бы |E|/2 (1.5 / 2.5 / 7.5 / 6.0 соответственно).
* Аргмакс Борна во всех примерах — оптимальный разрез.
* Известная честная граница: p=1 на чётном цикле C4 даёт ровно 3/4 рёбер
  (E[cut] = 3.0) — проверяется тестом `qaoa_bipartite_ring_p1`.

## 4. Шум MCWF: GHZ-8 (20 000 выстрелов, 8 гейтов)

| Пресет | Время | Наблюдение |
|---|---|---|
| ideal | 6.4 с | расхождение — только биномиальный шум сэмплинга |
| ibm-heron | 6.6 с | TVD ≈ 0.02–0.05, F_класс ≈ 0.999 |
| google-willow | 6.5 с | промежуточная деградация |
| noisy-90s | 7.4 с | TVD ≈ 0.5+, пик размазан по всем исходам |

Контрольные точки из смоука (GHZ-3, 4096 выстрелов, noisy-90s): TVD 0.319,
F_класс 0.679, χ² 440 (dof 1), пик 0.50 → 0.38.
Верификация + шум (`verify unitary qft --n 3 --noise ibm-heron --shots 4096`):
вердикт ДОКАЗАНО ТОЧНО (кольцо) + TVD 0.016, F_класс 0.9995, χ² 7.5 при
dof 7 — статистически неотличимо от идеального мультиномиального сэмплинга,
как и должно быть для честной калибровки Heron.

## 7. Выводы

1. Квантовый стек замкнут: **произвольная схема → точный режим → шум
   железа → формальный вердикт** — всё из одного шелла и одного
   MCP-инструмента, без внешних зависимостей.
2. QAOA на идеальном субстрате решает мелкие MaxCut до оптимума за
   секунды на 11 МБ RAM — на физическом железе те же углы деградируют
   ровно настолько, насколько честно закалиброван пресет (χ²-контроль).
3. Ресурсный потолок цикла Q: миллисекунды (qcasm), секунды (QAOA/MCWF),
   12 МБ RSS — уровень «лёгкой игры 2005 года» не достигается даже
   близко.
