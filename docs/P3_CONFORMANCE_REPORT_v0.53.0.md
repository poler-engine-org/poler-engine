**Цикл R (v0.53.0) — живое соединение POLER ENGINE (Rust) и P³ ENGINE (Zig).**
Дата: 2026-09-23. Все числа ниже воспроизводимы командами из этого отчёта.

## 1. R1 — Воспроизведение P³

План (§4) требовал `zig build test` на машине с Zig 0.14.0. По директиве
владельца от 2026-09-22 («всегда можно накатить Ubuntu внутри POLER BOX —
оно сжимает всё, даже ОС, в реальном времени») тулчейн развёрнут прямо в

| Параметр | Значение |

| Прогон | `zig build test --summary all` |

| MaxRSS на тест-степ | 4–14 МБ |

фаз 8–10 (алгебра, UI-порт LyShine, O3DE-математика, скелетная анимация).

## 2. R2 — C-ABI конформанс Rust ↔ Zig

### 2.1 Мост

`P3_Engine/src/p3_ffi.zig` (~640 строк, новый) экспортирует через C-ABI
поверх настоящего ядра (`p3_kernel.zig`, `p3_idempotent.zig`) — без
дублирования математики:

- `p3ffi_fs_distance(a, b)` — метрика Фубини–Штуди;
- `p3ffi_pgl_{identity,mul,transpose,apply,det}` — действия PGL(4,ℝ);
- `p3ffi_givens4(i, j, θ)` — ортогональные генераторы;
- `p3ffi_spectral_projector(v)` — ранг-1 проектор vvᵀ/vᵀv;
- `p3ffi_idempotent_{rank,residual}`, `p3ffi_ortho_residual`;
- `p3ffi_render_frame(…)` — софтверный P³-растеризатор (тройной буфер);
- `p3ffi_abi_version()`, `p3ffi_kernel_tag()` — рукопожатие.

Сборка: `zig build p3-ffi -Doptimize=ReleaseFast` → `libp3ffi.so`
(82 КБ, x86_64-linux-gnu). Артефакт коммитится в репозиторий:
`ffi/libp3ffi-linux-x86_64.so`,
sha256 `298f38e8…5ae8`. Пересборка — `ffi/build.sh`.

Rust-сторона (`src/p3/`): `ffi.rs` (dlopen без внешних крейтов, поиск
`P3_FFI_LIB` → рядом с бинарником → `ffi/` репо), `native.rs` —
**независимый Rust-близнец** той же математики. Фикстуры генерируются
одним детерминированным xorshift64 на Rust и уходят в Zig байт-в-байт —
«живые фикстуры», расхождений по построению не может быть, и они
проверяются.

### 2.2 Результаты (`p3 conformance --pairs 256`, release-бинарник)

| Категория | Проверок | макс\|Δ\| | Допуск |
|---|---:|---:|---|
| d_FS(a,b) Rust ↔ Zig | 258 | 2.220e-16 | 1e-12 |
| гомогенность d_FS(λa, μb) | 512 | 1.277e-15 | 1e-9 |
| U†U = I (Гивенс-композиции) | 256 | 0.000e0 | 1e-12 |
| ‖UᵀU − I‖ (остаток обеих сторон) | 512 | 4.441e-16 | 1e-12 |
| (A·B)v = A(Bv) + Rust ↔ Zig | 512 | 1.066e-14 | 1e-9 |
| det(PGL4) относительная | 256 | 0.000e0 | 1e-9 |
| проектор P = vvᵀ/vᵀv Rust ↔ Zig | 256 | 2.220e-16 | 1e-12 |
| ‖P² − P‖ и ‖(I−P)² − (I−P)‖ | 768 | 2.220e-16 | 1e-12 |

**Вердикт: КОНФОРМАНС ПОДТВЕРЖДЁН.** Все расхождения — на уровне
машинного эпсилона f64 (2.2e-16 = 1 ulp у 1.0). Требования плана
выполнены с запасом в 4–5 порядков: d_FS совпадает в пределах
f64-честности; U†U = I; идемпотенты P² = P согласованы на одинаковых
матрицах. Special-cases: ортогональные векторы → точно π/2;
антиподальные (λ < 0) → 0 — антиподальное отождествление RP³ обе
стороны трактуют одинаково.

## 3. R3 — «Кадр из гамильтониана»

**Первый публичный артефакт «изображение, просчитанное математически».**
Пайплайн (`p3 frame`, `src/p3/render.rs` + `p3ffi_render_frame`):

```text
H = −J·Σ ZᵢZᵢ₊₁ − h·Σ Xᵢ      цепочка Изинга, POLER calc (Rust)
        │  expm(−iHt) — унитарная эволюция, 65 срезов
        ▼
worldlines ⟨Zᵢ⟩(t)              6 цветных траекторий (сегменты 1..6)
облако |⟨b|Ψ(t)⟩|²              топ-10 базисных состояний на срез
«занавес»                       рёбра (b,t)→(b,t+dt): поток вероятности
бокс данных ±0.92³              пространственная отсылка (сегмент 9)
        │  однородные координаты [x:y:z:1] — точки P³
        ▼
P³ рендер (Zig): центральная проекция орбитальной камеры,
  глубина = d_FS(точка, глаз) ∈ [0, π/2], z-буфер, Wu-антиалиасинг
        ▼
тройной буфер RGB + depth + seg → 3 PNG (свой энкодер, stored-deflate)
```

### 3.1 Артефакты (1280×720, n=6, J=1.0, h=0.9, 64 шага)

- `docs/demo/p3_frame_v0.53.0/p3_frame_n6_t64_j1_h0.9_rgb.png` —
  аннотированный публичный кадр (заголовок, легенда, метрики честности);
- `…_depth.png` — FS-глубина в градациях серого (близко = светло);
- `…_seg.png` — карта сегментации (какой объект записал пиксель).

### 3.2 Метрики честности

| Метрика | Значение |
|---|---|
| Дрейф энергии ⟨Ψ\|H\|Ψ⟩ за эволюцию | 9.3e-13 (унитарность expm) |
| Дрейф нормы ‖Ψ‖ | в том же 9.3e-13 |
| max d_FS в кадре | 1.0114 рад ≤ π/2 ✓ |
| Детерминированность | байт-в-байт (тест `frame_is_deterministic`) |
| PNG-валидность | независимый zlib-декодер (Python) + собственный round-trip |
| Визуальное QA | VLM-оценка 9/10 («presentable public scientific artifact») |

Изолированные точечные всплески в облаке — честные мгновенные пики
|⟨b|Ψ⟩|², существующие один срез; не рисовать их = скрывать данные.

## 4. Гарантии воспроизводимости

```bash
# конформанс (256 пар, ~1 с)
poler-engine --exec "p3 conformance --pairs 256"
# тот же кадр
poler-engine --exec "p3 frame --n 6 --steps 64 --size 1280x720 \
  --cloud 10 --out ./out"
# пересборка моста из исходников P³
ffi/build.sh /путь/к/P3_Engine   # Zig 0.14.0, ReleaseFast
```

Тесты: **2570/2570** workspace (+23 к v0.52.0: 18 p3-модуль, 5 шелл),
2079/2079 Zig. Машиночитаемый отчёт: `p3 conformance --json`.
